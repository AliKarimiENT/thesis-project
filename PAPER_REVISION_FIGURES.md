## Figure 1: Main Comparison Plot

**File**: `reports/figures/comparison_squad.png`  
**Size**: 113 KB  
**Resolution**: 300 dpi (publication-quality)  
**Format**: PNG (easily insertable in Word)

**Caption**:  
Comparison of automatic evaluation metrics between baseline and difficulty-controlled question generation models. BLEU score is normalized to 0-1 scale for visualization. Error bars represent standard deviations for ROUGE metrics. The baseline model shows slight advantages across all metrics, though differences are modest (<5% for most metrics).

**Figure Description (for paper text)**:  
Figure 1 presents a side-by-side comparison of six evaluation metrics for both models. The baseline model (shown in blue) consistently outperforms the controlled model (shown in orange) across all automatic metrics, with BLEU showing a 4.3% difference, ROUGE-L showing 4.7% difference, and QA answerability metrics showing larger gaps (EM: 24.1%, F1: 9.4%). These results indicate that with limited training data (1,000 samples), the simpler baseline model achieves better performance on surface-level similarity metrics.

**How to Insert in Word**:
1. Place cursor where you want the figure
2. Insert → Pictures → Select `comparison_squad.png`
3. Right-click image → Wrap Text → "In line with text" or "Top and bottom"
4. Add caption: Right-click → Insert Caption → "Figure 1: ..."
5. Resize if needed (suggested width: 6 inches)

## Figure 2: Question Length Distribution (Baseline)

**File**: `reports/figures/baseline_lengths.png`  
**Size**: ~80 KB (estimated)  
**Resolution**: 300 dpi  
**Format**: PNG

**Caption**:  
Distribution of question lengths for baseline model. Left panel shows predicted questions; right panel shows reference questions. Red dashed line indicates mean length. The baseline model generates questions with mean length 13.7 words (SD 6.3), compared to reference mean of 10.2 words (SD 3.5).

**Figure Description (for paper text)**:  
Figure 2 illustrates the length distribution of questions generated by the baseline model compared to reference questions. The predicted questions (left panel) show greater variability and longer average length than references (right panel), suggesting the model tends toward more verbose formulations. The distribution is roughly normal with a slight right skew, indicating occasional very long questions.
